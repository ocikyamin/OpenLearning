# Checklist Persiapan

Gunakan daftar ini untuk memastikan semuanya sudah siap sebelum mulai belajar Laravel.

---

## Checklist Awal (Semua Jalur)

- [ ] Laptop/PC siap digunakan
- [ ] Koneksi internet tersedia
- [ ] Sudah menentukan pilihan: **Laragon** atau **WSL + Ubuntu**
- [ ] File panduan sudah dibaca (jangan langsung skip)

---

## Checklist — Laragon

- [ ] Laragon Full sudah di-download & diinstall
- [ ] Apache dan MySQL berjalan (Start All → hijau)
- [ ] `http://localhost` muncul halaman Laragon
- [ ] `php -v` muncul versi PHP 8.3 / 8.4
- [ ] `composer -v` muncul versi Composer
- [ ] `laravel --version` muncul versi Laravel Installer
- [ ] Project Laravel sudah dibuat (`laravel new`)
- [ ] `npm install && npm run build` berhasil
- [ ] `composer run dev` berjalan
- [ ] `http://localhost:8000` muncul halaman Laravel

---

## Checklist — WSL + Ubuntu

- [ ] WSL 2 sudah terinstall
- [ ] Ubuntu sudah terinstall
- [ ] Apache terinstall dan berjalan
- [ ] PHP 8.3 / 8.4 / 8.5 terinstall
- [ ] MySQL terinstall dan berjalan
- [ ] Composer & Laravel Installer terinstall
- [ ] Node.js terinstall
- [ ] Git terinstall
- [ ] Project Laravel sudah dibuat (`laravel new`)
- [ ] `npm install && npm run build` berhasil
- [ ] `composer run dev` berjalan
- [ ] `http://localhost:8000` muncul halaman Laravel

---

## Checklist Project Laravel

- [ ] Project berhasil dibuat dengan `laravel new`
- [ ] `npm install && npm run build` berhasil
- [ ] `composer run dev` berjalan tanpa error
- [ ] Halaman welcome Laravel tampil di `http://localhost:8000`
- [ ] (Jika pakai MySQL) Database terhubung & migration berjalan

---

## Catatan

| Simbol | Arti |
|--------|------|
| ✅ | Sudah selesai |
| ⬜ | Belum dilakukan |
| ❌ | Ada error, perlu diperbaiki |
