# Memilih Jalur Instalasi

Sebelum memulai, teman-teman perlu memilih salah satu dari dua metode berikut. Keduanya sama-sama bagus, hanya berbeda pendekatan.

---

## Jalur A — Laragon (Direkomendasikan untuk Pemula)

| Kelebihan | Kekurangan |
|-----------|------------|
| Instalasi sekali klik, langsung jadi | Hanya untuk Windows |
| Sudah termasuk Apache, PHP, MySQL, Composer, Git | |
| Ada tampilan GUI (klik-klik, tidak perlu hafal perintah) | |
| Ringan, bisa dipindah-pindah folder | |

**Cocok untuk:** Mahasiswa yang ingin langsung coding tanpa banyak urusan teknis.

## Jalur B — WSL + Ubuntu

| Kelebihan | Kekurangan |
|-----------|------------|
| Lingkungan kerja mirip server sungguhan | Instalasi lebih panjang |
| Melatih penggunaan Linux sejak awal | Harus hafal perintah dasar terminal |
| Lebih dekat dengan dunia kerja | Butuh RAM minimal 8 GB |

**Cocok untuk:** Mahasiswa yang penasaran dengan Linux dan ingin tantangan lebih.

---

## Bagaimana Memilih?

| Kondisi | Pilih |
|---------|-------|
| RAM ≤ 4 GB | **Laragon** |
| RAM ≥ 8 GB & ingin yang mudah | **Laragon** |
| RAM ≥ 8 GB & ingin belajar Linux | **WSL + Ubuntu** |
| Ingin cepat selesai instalasi | **Laragon** |
| Spesifikasi laptop pas-pasan | **Laragon** |

> **Catatan:** Tidak ada pilihan yang salah. Jika memulai dengan Laragon lalu penasaran dengan WSL, teman-teman bisa mencobanya nanti. Yang penting saat ini adalah ** lingkungan development siap** sehingga kita bisa fokus belajar Laravel.

---

## Apa yang Perlu Disiapkan (Terlepas dari Jalur Manapun)

- Laptop/PC dengan koneksi internet
- Kuota internet ~2-3 GB (untuk download software dan package)
- Waktu 1-2 jam untuk instalasi dan konfigurasi
- Minat belajar yang tinggi (ini yang paling penting)
