## **BAB 8 – Pemrograman PHP dengan framework**

### 8.1 Latar Belakang

Dalam pengembangan aplikasi web modern, penggunaan framework telah menjadi kebutuhan utama untuk meningkatkan produktivitas, keamanan, dan keteraturan kode. Salah satu framework PHP yang populer dan ringan adalah **CodeIgniter 4**. Framework ini dirancang dengan prinsip **MVC (Model-View-Controller)** sehingga memudahkan pengembang dalam memisahkan logika bisnis, tampilan, dan pengelolaan data.

### 8.2 Tujuan Pembelajaran

Setelah menyelesaikan modul ini, mahasiswa diharapkan mampu:

1. Memahami konsep MVC pada CodeIgniter 4.
2. Menginstal dan mengonfigurasi CodeIgniter 4 dengan Composer dan XAMPP.
3. Membangun aplikasi web dinamis menggunakan Controller, Model, dan View.
4. Mengimplementasikan CRUD, Validasi, Upload File, dan Login System.
5. Mengelola relasi antar tabel menggunakan Query Builder dan Join.
6. Menghasilkan aplikasi manajemen data berbasis web dengan tampilan responsif (Bootstrap 5).


### 8.3 Alat dan Bahan

* **Software:**

  * XAMPP (Apache, PHP, MySQL)
  * Composer (Dependency Manager PHP)
  * Visual Studio Code (Text Editor)
  * Browser (Google Chrome / Edge)
* **Framework & Library:**

  * CodeIgniter 4
  * Bootstrap 5
* **Database:**

  * MySQL
* **Pengetahuan Dasar yang Dibutuhkan:**

  * PHP Dasar
  * SQL Query (SELECT, INSERT, UPDATE, DELETE)

### 8.4 Konsep MVC (Model-View-Controller)

Sebelum mulai praktik, pahami konsep dasar arsitektur yang digunakan CodeIgniter.

| Komponen       | Fungsi                                             |
| -------------- | -------------------------------------------------- |
| **Model**      | Mengatur logika data dan interaksi dengan database |
| **View**       | Mengatur tampilan yang dilihat pengguna (UI)       |
| **Controller** | Menjembatani antara pengguna, view, dan model      |

Contoh alur sederhana:
**User membuka URL → Controller memproses permintaan → Model mengambil data dari database → View menampilkan data.**

---

### 8.5 Struktur Folder CodeIgniter 4

Berikut struktur utama yang perlu dipahami:

```

app/
 ├── Controllers/
 ├── Models/
 ├── Views/
public/
system/
writable/
```

* **Controllers:** berisi logika aplikasi.
* **Models:** berisi interaksi database.
* **Views:** berisi file tampilan (HTML, CSS, JS).
* **Public:** direktori utama yang diakses oleh browser.
* **System:** core framework.
* **Writable:** tempat penyimpanan log dan cache.

## **BAB 9 – Pengenalan CodeIgniter 4 dan Instalasi Lingkungan Pengembangan**


### 9.1 Tujuan

Setelah pertemuan ini mahasiswa mampu:

* Menjelaskan konsep MVC dan arsitektur CodeIgniter 4.
* Menginstal CodeIgniter 4 menggunakan Composer.
* Menjalankan aplikasi pertama menggunakan `php spark serve`.
* Mengatur konfigurasi dasar aplikasi dan koneksi database.



### 9.2 Mengapa CodeIgniter 4?

Beberapa keunggulan CodeIgniter 4:

1. **Ringan & Cepat:** Tidak membutuhkan banyak konfigurasi.
2. **Modern:** Mendukung PHP 8+, Namespaces, Composer, dan Routing baru.
3. **Keamanan:** Mendukung CSRF Protection, Validasi Input, dan Session Management.
4. **Struktur Teratur:** Menggunakan MVC sehingga mudah dikembangkan tim.


### 9.3 Langkah Praktikum

#### **Langkah 1 – Menyiapkan XAMPP dan Composer**

1. Jalankan **XAMPP Control Panel**, aktifkan `Apache` dan `MySQL`.
2. Pastikan **Composer** telah terpasang. Cek versi dengan:

   ```bash

   composer -V
   ```
3. Jika belum, unduh di [https://getcomposer.org/](https://getcomposer.org/)



#### **Langkah 2 – Membuat Project CodeIgniter 4**

Buka terminal / CMD di folder `htdocs`, jalankan:

```bash

composer create-project codeigniter4/appstarter belajarci4
```

Composer akan mengunduh CodeIgniter ke folder `belajarci4`.

---

#### **Langkah 3 – Menjalankan Server**

Masuk ke folder proyek:

```bash

cd belajarci4
php spark serve
```

Akses di browser:

```

http://localhost:8080
```

Jika berhasil, muncul tampilan *Welcome to CodeIgniter 4!*

---

#### **Langkah 4 – Konfigurasi Dasar**

1. Salin file `.env.example` menjadi `.env`

2. Aktifkan baris berikut:

   ```

   app.baseURL = 'http://localhost:8080/'
   ```

3. Buat database di phpMyAdmin:

   ```sql

   CREATE DATABASE belajarci4;
   ```

4. Di file `.env`, aktifkan koneksi:

   ```

   database.default.hostname = localhost
   database.default.database = belajarci4
   database.default.username = root
   database.default.password =
   database.default.DBDriver = MySQLi
   ```

---

#### **Langkah 5 – Struktur Folder**

Buka proyek di VS Code → Pahami folder:

```

app/
 ├── Controllers/
 ├── Models/
 ├── Views/
```

---

### 9.4 Latihan Mahasiswa

1. Jalankan project CodeIgniter 4 dan tampilkan halaman utama di browser.
2. Ganti tulisan “Welcome to CodeIgniter 4” pada halaman utama menjadi nama Anda.

## *BAB 10 – Routing, Controller, dan View pada CodeIgniter 4*


### 10.1 Tujuan

Setelah pertemuan ini mahasiswa mampu:

* Memahami konsep Routing dan Controller.
* Membuat View untuk menampilkan halaman web.
* Menghubungkan Route–Controller–View dalam satu alur kerja.
* Membuat layout dengan Bootstrap 5.


### 10.2 Teori Singkat

#### **Routing**

Routing berfungsi mengatur arah permintaan URL agar mengarah ke fungsi (method) tertentu pada Controller.

Contoh:

```php

$routes->get('/', 'Home::index');
```

Artinya: ketika user membuka `/`, maka akan menjalankan method `index()` di Controller `Home`.

#### **Controller**

Controller berfungsi mengatur logika program. Semua interaksi antara pengguna dan sistem diproses melalui Controller.

#### **View**

View menampilkan hasil ke pengguna. Biasanya berupa file HTML yang dapat dipadukan dengan Bootstrap untuk tampilan menarik.

---

### 10.3 Langkah Praktikum

#### **Langkah 1 – Membuat Controller Baru**

1. Buat file `Home.php` di folder `app/Controllers`:

   ```php

   <?php
   namespace App\Controllers;

   class Home extends BaseController
   {
       public function index()
       {
           return view('home');
       }

       public function about()
       {
           return view('about');
       }
   }
   ```

   Controller ini memiliki dua method: `index()` dan `about()`.

---

#### **Langkah 2 – Menambahkan Route**

Edit `app/Config/Routes.php`:

```php

$routes->get('/', 'Home::index');
$routes->get('/about', 'Home::about');
```

---

#### **Langkah 3 – Membuat View**

Buat folder `app/Views`, tambahkan file:

**home.php**

```html

<!DOCTYPE html>
<html>
<head>
  <title>Beranda</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="bg-light">
  <div class="container py-5">
    <h1 class="text-center">Selamat Datang di CodeIgniter 4</h1>
    <p class="text-center text-muted">Framework PHP yang ringan dan cepat.</p>
    <a href="/about" class="btn btn-primary d-block mx-auto" style="width:200px;">Tentang Aplikasi</a>
  </div>
</body>
</html>
```

**about.php**

```html

<!DOCTYPE html>
<html>
<head>
  <title>Tentang</title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body class="bg-white">
  <div class="container py-5">
    <h1 class="text-center">Tentang Aplikasi</h1>
    <p class="text-center">Aplikasi ini dibuat menggunakan CodeIgniter 4 dan Bootstrap 5.</p>
    <a href="/" class="btn btn-outline-secondary d-block mx-auto" style="width:200px;">Kembali</a>
  </div>
</body>
</html>
```

---

#### **Langkah 4 – Menjalankan Aplikasi**

Ketik di terminal:

```bash

php spark serve
```

Lalu buka:

* `http://localhost:8080/` → Halaman Beranda
* `http://localhost:8080/about` → Halaman Tentang

---

#### **Langkah 5 – Membuat Template Layout**

Untuk menghindari pengulangan, buat template layout:

**layout.php**

```html

<!DOCTYPE html>
<html>
<head>
  <title><?= $title ?? 'Aplikasi CI4'; ?></title>
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css" rel="stylesheet">
</head>
<body>
  <nav class="navbar navbar-expand-lg navbar-dark bg-primary">
    <div class="container">
      <a class="navbar-brand" href="/">Belajar CI4</a>
      <div>
        <a href="/" class="nav-link d-inline text-white">Home</a>
        <a href="/about" class="nav-link d-inline text-white">About</a>
      </div>
    </div>
  </nav>
  <div class="container py-4">
    <?= $this->renderSection('content'); ?>
  </div>
</body>
</html>
```

Gunakan pada **home.php**:

```php

<?= $this->extend('layout'); ?>
<?= $this->section('content'); ?>
  <h2 class="text-center mt-4">Selamat Datang di Aplikasi CodeIgniter 4</h2>
  <p class="text-center">Framework PHP modern untuk membangun aplikasi web cepat dan terstruktur.</p>
<?= $this->endSection(); ?>
```
