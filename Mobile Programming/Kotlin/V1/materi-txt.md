Saya ingin Anda membantu saya membuat **Bahan Ajar** untuk mata kuliah "Pemrograman Mobile II" menggunakan **Kotlin** dan **Android Studio**. 

Karakteristik bahan ajar yang saya inginkan:
- Ditulis dalam **bahasa Indonesia** dengan gaya penjelasan sederhana, runut, dan mudah dipahami mahasiswa semester 3–5.
- Terdiri dari beberapa **Bab/Subbab** sesuai capaian pembelajaran berikut:

1. Antarmuka pengguna (UI) dasar dengan TextView, Button, dan atribut XML.
2. Activity dan View Group (ImageView), serta layout dasar seperti LinearLayout.
3. Form input (EditText) dan layout lanjutan: RelativeLayout & ConstraintLayout.
4. Spinner, String, Toast, dan Event OnClick.
5. Logika bisnis dengan dasar Kotlin (variabel, tipe data, operator, aritmatika).
6. Struktur kontrol alur program (percabangan), style, dan tema aplikasi.
7. Navigasi antar layar dengan Intent dan AndroidManifest.
8. Animasi dasar pada aplikasi Android.
9. Penyimpanan data lokal dengan Room Database.
10. Pertukaran data dengan server menggunakan RESTful API (JSON tampil data).
11. Operasi CRUD dengan RESTful API (tambah, edit, delete).
12. Kolaborasi pengembangan aplikasi kelompok, build APK, dan publikasi ke Google Play Store.
13. Presentasi dan diskusi aplikasi hasil karya.

- Setiap bab berisi:
  - Tujuan pembelajaran
  - Materi pokok (penjelasan konsep)
  - Ilustrasi/gambar kode (contoh XML/Kotlin)
  - Ringkasan
  - Pertanyaan refleksi atau latihan kecil (opsional)

- Hindari bagian administrasi seperti kontrak kuliah, motivasi, atau silabus.
- Susun dalam format **Markdown** agar mudah diubah ke PDF/Slide.

Tolong buatkan **outline lengkap** dulu sebelum menuliskan isi detail tiap bab.
