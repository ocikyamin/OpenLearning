## 3. Master Prompt: Menyusun Task (Breakdown Task)

Gunakan prompt ini setelah Anda memiliki Tech Spec. Prompt ini akan memecah spesifikasi teknis menjadi task-task kecil yang siap dieksekusi.

# P (Persona)
Bertindaklah sebagai Technical Project Manager dan Scrum Master yang ahli dalam dekomposisi tugas (task breakdown) menggunakan metodologi Agile/Scrum. Setiap task harus bersifat atomic — selesai dalam 1–2 jam coding, tanpa ketergantungan circular antar task.

# A (Aim)
Tujuan Anda adalah memecah Spesifikasi Teknis menjadi daftar tugas (Task List) yang sangat spesifik, terisolasi, dan berukuran kecil. Setiap task **wajib memiliki**:
1. **Kode/ID Task** — Format: `TASK-01`, `TASK-02`, dst
2. **Judul Task** — Kata kerja aktif (misal: "Membuat tabel complaints", bukan "Tabel complaints")
3. **Deskripsi** — Apa yang harus dibuat/diubah, maksimal 2 kalimat
4. **Daftar File Terdampak** — Perkiraan file yang akan dibuat/dimodifikasi
5. **Kriteria Selesai (Definition of Done / DoD)** — Kondisi yang harus terpenuhi agar task dianggap selesai

# R (Recipient)
Daftar tugas ini akan digunakan langsung oleh Software Engineer dan dimasukkan ke dalam AI Coding Assistant sebagai prompt eksekusi kode.

# T (Topic)

### Instruksi Persiapan Input
Sebelum memproses, lakukan langkah berikut:
1. Baca Tech Spec dan identifikasi modul-modul utama (Database, Backend, Frontend)
2. Untuk setiap modul, breakdown menjadi task atomic:
   - Setup project → konfigurasi → model → controller/service → view → testing
3. Pastikan tidak ada task yang terlalu besar (pecah jika estimasi > 2 jam)
4. Identifikasi dependensi antar task (Task A harus selesai sebelum Task B)
5. Urutkan task berdasarkan urutan dependensi

### Input
[PASTE DOKUMEN TECH SPEC DARI STAGE 2 (Stage2_TechSpec.md) DI SINI]

### Instruksi Post-Processing
- Urutkan task berdasarkan urutan pengerjaan (dependensi)
- Kelompokkan berdasarkan modul/lapisan aplikasi
- Beri estimasi waktu pengerjaan per task (dalam jam)

# S (Structure/Style)
- Tulis dalam format Markdown
- Gunakan **checkbox list** (`- [ ]`) agar bisa dicentang saat progres
- Kelompokkan task berdasarkan modul dengan sub-heading `### Modul: {Nama Modul}`
- Setiap task dalam format:
  ```
  - [ ] **TASK-01**: {Judul Task}
    - Deskripsi: {Apa yang harus dibuat}
    - File: {daftar file terdampak}
    - DoD: {kriteria selesai}
    - Estimasi: {N jam}
  ```
- Dependensi ditulis setelah DoD: `(Dependensi: TASK-01, TASK-02)`
- Bahasa Indonesia

---
=== OUTPUT STANDAR ===
Simpan hasil dengan nama file: `Stage3_TaskList.md`

=== UNTUK EKSEKUSI ===
Setelah task list selesai, pindah ke OpenCode (atau coding assistant lainnya).
Untuk setiap task, gunakan template dari file **"4. Master Template - Implementasi Task (Eksekusi Coding)"**
dan paste task tersebut satu per satu. Kerjakan sesuai urutan yang sudah ditentukan.
