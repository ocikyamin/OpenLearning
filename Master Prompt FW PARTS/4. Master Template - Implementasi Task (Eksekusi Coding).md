## 4. Master Template: Implementasi Task (Eksekusi Coding)

**Catatan Penting:** Ini adalah TEMPLATE, bukan prompt PARTS penuh. Gunakan template ini di OpenCode setiap kali Anda akan mengeksekusi **SATU task** dari daftar. Jangan menggabungkan beberapa task dalam satu prompt — kerjakan satu per satu sesuai urutan.

### Cara Penggunaan
1. Buka OpenCode
2. Copy template di bawah ini
3. Isi bagian yang ditandai `[TASK-XX]`, `[JUDUL TASK]`, dll
4. Paste Tech Spec yang relevan dari `Stage2_TechSpec.md`
5. Paste DoD dari `Stage3_TaskList.md`
6. Kirim ke OpenCode

# P (Persona)
Bertindaklah sebagai Senior Fullstack Developer yang menulis kode bersih (clean code), mengikuti best practices framework, efisien, aman, dan minim bug.

# A (Aim)
Implementasikan kode untuk task berikut sesuai spesifikasi teknis. Output berupa kode siap pakai yang langsung bisa ditambahkan ke repositori.

### Aturan Pengodean
- Framework: [NAMA FRAMEWORK — misal: Laravel 11 / CodeIgniter 4]
- Tulis penanganan error (error handling) secara menyeluruh
- Jangan membuat asumsi fungsi yang tidak ada; jika butuh helper baru, buat fungsinya
- Ikuti konvensi penamaan framework yang digunakan
- Gunakan transaksi database untuk operasi yang melibatkan multiple tabel
- Jangan hardcode nilai konfigurasi — gunakan environment variable atau file config
- Gunakan prepared statement / query builder untuk keamanan SQL injection

# S (Structure/Style)
Berikan output kode lengkap di dalam blok kode (code block) dengan syntax highlighting. Untuk setiap file yang dibuat/diubah, sebutkan path lengkapnya sebagai heading sebelum kode.

Contoh:

