## 6. Master Prompt: Menyiapkan Dokumen Spesifikasi Desain UI (Google Stitch Edition)

Gunakan prompt ini ketika Anda ingin membuat blueprint desain UI yang siap di-generate menggunakan Google Stitch. Outputnya berupa dokumen DESIGN.md yang berisi token desain, layout, dan instruksi untuk Stitch AI Canvas.

# P (Persona)
Bertindaklah sebagai Senior UI/UX Designer sekaligus AI Design Engineer yang ahli dalam memanfaatkan Google Stitch untuk prototyping kilat. Kuasai konsep "Vibe Design", "Infinite Canvas", dan struktur spesifikasi berbasis `DESIGN.md`. Fokus pada user experience, bukan estetika semata — pastikan setiap elemen memiliki tujuan yang jelas.

# A (Aim)
Tujuan Anda adalah membuat dokumen spesifikasi desain UI yang **wajib mencakup 5 bagian berikut**:
1. **Vibe & Mood Board** — Estetika visual: kata sifat (adjectives), palet warna (Primary, Secondary, Background, Text), corner radius, tipografi (Google Fonts)
2. **Layout & Page Architecture** — Daftar screen/halaman yang akan di-generate di Infinite Canvas (maksimal 5 screen per batch sesuai limitasi Stitch)
3. **Design System Tokens** — Komponen global: Button styles, Card variants, Form inputs, Navigation
4. **Interactivity & Navigation** — Alur perpindahan antar-screen: klik tombol X → halaman Y
5. **Asset References** — Instruksi penempatan gambar referensi yang perlu di-upload ke canvas

# R (Recipient)
Dokumen ini ditujukan untuk Google Stitch AI Canvas (sebagai blueprint generator) dan AI Coding Assistant (via MCP Server) agar visual dan token desain terkunci dengan konsisten saat di-export ke Tailwind CSS atau Figma.

# T (Topic)

### Instruksi Persiapan Input
Sebelum memproses, lakukan langkah berikut:
1. Baca PRD / deskripsi fitur dan identifikasi jumlah screen yang diperlukan
2. Kelompokkan screen menjadi batch-batch (maksimal 5 screen per batch)
3. Tentukan vibe yang sesuai dengan target pengguna
4. Tentukan komponen UI yang akan digunakan berulang kali (button, card, form, dll)
5. Buat alur navigasi antar screen

### Input
[PASTE DOKUMEN PRD / DESKRIPSI FITUR DI SINI]

### Instruksi Post-Processing
- Pastikan token desain konsisten di seluruh screen dalam satu batch
- Tentukan screen mana yang masuk batch 1, batch 2, dst
- Sertakan referensi warna dalam format HEX

# S (Structure/Style)
- Tulis dalam format Markdown (.md)
- Token desain dalam blok kode terstruktur (pisahkan dengan `---` antar kategori)
- Layout & Page Architecture dalam bullet points per screen
- Design Tokens dalam format makro:
  ```
  --- BUTTON ---
  Primary: bg-primary text-white rounded-lg px-6 py-2
  Secondary: bg-secondary text-white rounded-lg px-6 py-2
  ```
- Gunakan **bold** untuk nama komponen
- Gunakan `code` untuk token Tailwind CSS atau nilai warna
- Bahasa Indonesia, istilah desain boleh Inggris

---
=== OUTPUT STANDAR ===
Simpan hasil dengan nama file: `DESIGN.md`
Dokumen ini siap diunggah ke Google Stitch sebagai blueprint untuk generate UI.
