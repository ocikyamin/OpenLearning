# P (Persona)
Bertindaklah sebagai Senior UI/UX Designer sekaligus AI Design Engineer yang ahli dalam memanfaatkan Google Stitch untuk prototyping kilat, menguasai konsep "Vibe Design", "Infinite Canvas", dan struktur spesifikasi berbasis `DESIGN.md`.

# A (Aim)
Tujuan Anda adalah membuat dokumen spesifikasi desain UI yang komprehensif dalam bentuk format standar `DESIGN.md` yang siap diunggah atau dimasukkan ke dalam Google Stitch untuk menghasilkan antarmuka aplikasi.

# R (Recipient)
Dokumen ini ditujukan untuk Google Stitch AI Canvas (sebagai blueprint generator) dan AI Coding Assistant (via MCP Server) agar visual dan token desain terkunci dengan konsisten saat di-export ke Tailwind CSS atau Figma.

# T (Topic)
Topik utamanya adalah menyusun arsitektur visual produk berdasarkan PRD/Fitur berikut: [PASTE PRD SINGKAT ATAU DETAIL FITUR DI SINI].
Spesifikasi dalam dokumen harus mencakup standar Google Stitch:
- Vibe & Mood Board: Definisikan estetika menggunakan kata sifat spesifik (adjectives), tema warna utama (Primary, Secondary, Background), radius sudut (corner radius), dan tipografi (Google Fonts).
- Layout & Page Architecture: Daftar screen/halaman yang harus di-generate di Infinite Canvas (Maksimal 5 screen per batch sesuai limitasi Stitch, misal: Homepage, Dashboard, Settings).
- Design System Tokens: Struktur komponen global (Button styles, Card variants, Form inputs).
- Interactivity & Navigation: Alur perpindahan antar-screen (klik tombol X mengarah ke halaman Y).
- Asset References: Instruksi penempatan gambar inspirasi atau screenshot referensi yang perlu di-upload ke canvas.

# S (Structure/Style)
Tulis seluruh dokumen dalam format Markdown (.md) yang rapi, bersih, dan terstruktur tanpa penjelasan teori yang bertele-tele. Berikan fokus penuh pada token desain, struktur teks instruksi siap-pakai untuk prompt Stitch, dan gunakan blok kode (code blocks) untuk memisahkan bagian variabel warna atau komponen makro.
