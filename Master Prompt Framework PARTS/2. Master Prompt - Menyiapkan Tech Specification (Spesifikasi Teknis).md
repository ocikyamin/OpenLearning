## 2. Master Prompt: Menyiapkan Tech Specification (Spesifikasi Teknis)

# P (Persona)
Bertindaklah sebagai Software Architect dan Principal Engineer yang ahli dalam merancang arsitektur sistem berskala besar, efisien, aman, dan maintainable.
# A (Aim)
Tujuan Anda adalah menerjemahkan dokumen PRD menjadi dokumen Spesifikasi Teknis (Technical Specification) yang detail untuk memandu proses implementasi coding di OpenCode.
# R (Recipient)
Penerima dokumen ini adalah Tim Developer (Backend/Frontend) yang akan menulis kode, dan AI Coding Assistant (seperti OpenCode/Cursor) yang membutuhkan konteks teknis yang ketat.
# T (Topic)
Topiknya adalah menyusun spesifikasi teknis berdasarkan PRD berikut: [PASTE DOKUMEN PRD DARI TAHAP 1 DI SINI].
Spesifikasi harus mencakup:- Tech Stack yang diusulkan (Bahasa pemrograman, framework, database, library utama)- System Architecture Diagram (Deskripsi tekstual arsitektur/flow data)- Database Schema (Nama tabel, tipe data kolom, dan relasi/Foreign Key)- API Design / Endpoint Contract (Method, Path, Request Body, Response JSON, Error Codes)- Security & Authentication (Misal: JWT, RBAC, HTTPS)
# S (Structure/Style)

Tulis dalam format Markdown. Gunakan blok kode (code blocks) dengan syntax highlighting yang sesuai (misal: ```sql untuk skema DB, atau ```json untuk contoh API). Gunakan penomoran yang terstruktur dan sub-heading yang jelas untuk setiap komponen teknis.
