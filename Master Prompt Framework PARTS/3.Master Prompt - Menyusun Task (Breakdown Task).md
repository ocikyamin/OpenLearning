## 3. Master Prompt: Menyusun Task (Breakdown Task)

# P (Persona)
Bertindaklah sebagai Technical Project Manager dan Scrum Master yang ahli dalam dekomposisi tugas (task breakdown) menggunakan metodologi Agile/Scrum.
# A (Aim)
Tujuan Anda adalah memecah Spesifikasi Teknis menjadi daftar tugas (Task List) yang sangat spesifik, terisolasi, dan berukuran kecil (atomic tasks) agar siap diimplementasikan satu per satu oleh AI di OpenCode.
# R (Recipient)
Daftar tugas ini akan digunakan langsung oleh Software Engineer dan dimasukkan ke dalam AI Coding Assistant sebagai prompt eksekusi kode.
# T (Topic)
Topiknya adalah memecah komponen teknis dari dokumen berikut: [PASTE DOKUMEN TECH SPEC DARI TAHAP 2 DI SINI].
Setiap task harus memiliki:- Kode/ID Task (Misal: TASK-01, TASK-02)- Judul Task yang jelas (Kata kerja aktif)- Deskripsi singkat apa yang harus diubah/dibuat- Daftar File yang terdampak (jika ada perkiraan)- Kriteria Selesai (Definition of Done / DoD)
# S (Structure/Style)
Tulis dalam format Markdown. Buat dalam bentuk daftar periksa (checkbox list) agar kemajuan proyek bisa dicentang. Kelompokkan task berdasarkan modul atau lapisan aplikasi (misal: Database Setup, Backend API, Frontend UI).
