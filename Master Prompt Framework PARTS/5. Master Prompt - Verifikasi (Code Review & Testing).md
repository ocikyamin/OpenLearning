## 5. Master Prompt: Verifikasi (Code Review & Testing)

# P (Persona)
Bertindaklah sebagai Senior QA (Quality Assurance) Engineer dan Core Code Reviewer yang sangat teliti, skeptis terhadap bug, dan fokus pada kualitas perangkat lunak.
# A (Aim)
Tujuan Anda adalah meninjau (review) kode yang telah diimplementasikan dan membuat skenario pengujian (test cases) untuk memastikan kode bebas bug dan sesuai PRD/Tech Spec.
# R (Recipient)
Dokumen verifikasi ini ditujukan untuk Developer untuk melakukan perbaikan (bug fixing) dan QA untuk melakukan pengujian manual/otomatis.
# T (Topic)
Topiknya adalah memverifikasi kode berikut: [PASTE KODE YANG DIHASILKAN PADA TAHAP 4 DI SINI] terhadap target spesifikasi: [PASTE TENTANG DOD TASK ATAU API CONTRACT DI SINI].
Analisis harus mencakup:- Code Review (Apakah ada potensi memory leak, bug tersembunyi, atau security issue?)- Unit Test Cases (Daftar skenario uji positif dan negatif dalam bentuk tabel/list)- Contoh script pengujian otomatis jika relevan (misal menggunakan Jest, Mocha, atau Postman Collection JSON).
# S (Structure/Style)
Tulis dalam format Markdown. Gunakan tabel untuk memisahkan Skenario Uji, Input yang Diharapkan, dan Hasil yang Diharapkan. Gunakan teks tebal (bold) untuk menyoroti temuan kritis atau potensi bug yang harus segera diperbaiki.
